CRIS ECO-001 — Single-Screen Command Board

- แทนที่ Executive Dashboard แบบ Scroll ด้วย Fixed Command Board
- แสดง Overall Readiness, Fleet, Mission, Ships, Issues, AI Brief และ Actions ในจอเดียว
- รายละเอียดทุกประเภทเปิดผ่าน Modal โดยไม่ขยายความสูงของหน้า
- Modal แสดง Current Status, Root Cause, Mission Impact, Recommended Action และ Evidence
- ปิด Modal แล้วกลับสู่ตำแหน่งเดิมทันที
- ปรับ MainLayout เฉพาะหน้า Command Center ให้ใช้พื้นที่หน้าจอเต็มและซ่อน Footer
- Mobile เลื่อนได้เท่าที่จำเป็น ส่วน Desktop ไม่มีการ Scroll ข้อมูลหลัก
- คง Business Logic, Decision Engine และ Domain Model เดิม
