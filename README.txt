CRIS CDE 2.2 – Real Thailand Offline Map

ไฟล์ที่นำไปแทนที่:
1. src/components/command/OperationalMap.tsx
2. public/operational-map-thailand.svg

คำสั่งใช้งาน:
unzip -o CRIS_CDE_2_2_REAL_THAILAND_MAP.zip
rm CRIS_CDE_2_2_REAL_THAILAND_MAP.zip
npm run build
npm run dev

หมายเหตุ:
- แผนที่เป็นไฟล์ Offline SVG
- ไม่ใช้ Google Maps
- ไม่ใช้ API Key
- จุดปฏิบัติการเป็นข้อมูลสาธิต ไม่ใช่พิกัดจริง
